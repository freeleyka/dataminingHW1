## Development Environment

- Jupyter Notebook
- Anaconda Navigator
- Python 3
- Pandas
- scikit-learn
- Seaborn 

## How to Run

1. Open Anaconda Navigator.
2. Launch Jupyter Notebook.
3. Open the FreeleyHW1.ipynb notebook.
4. Ensure the required dataset is in the appropriate directory (modify the path shortcut if necessary).
5. Run the notebook cells from beginning to end.

## Dataset

Iris Dataset:
features include:

- Sepal length
- Sepal width
- Petal length
- Petal width

The class feature is the target variable, used for classification.
